An open-source interactive geospatial web portal and destination companion for coastal Honnavar, Karnataka, India.

## Live Portal
🌐 **[View the Live Interactive Guide](https://jeeva-k-k.github.io/honnavar-coastal-guide/)**

## Destinations Mapped
- **Lopez Paradise Homestay (Basecamp):** Pragati Nagar, Kelginuru, Kasarkoda 581342 (`14.244209, 74.446930`). [Website](https://lopezparadise.in/)
- **Kasarkod Blue Flag Eco Beach:** 3.4 km from basecamp. [Guide](https://lopezparadise.in/honnavar-beach/)
- **Sharavathi Kandla Mangrove Boardwalk:** 3.4 km by car / 2.6 km by bike. [Details](https://lopezparadise.in/honnavar/)
- **Sharavathi Backwater Boating Jetty:** 2.1 km from basecamp.
- **Apsarakonda Eco-Heritage Promontory:** 1.7 km beach / 2.5 km falls. [Sunset Viewpoint](https://lopezparadise.in/apsarakonda/)
